SHEPHERD · SITE PLAN · FIG. 1

shepherd coordinates coding agents. It is a Herdr plugin built around one Rust program, shep: tasks move through configurable pipelines of steps, each step is a script in any language, and every part of the system communicates through a single shared SQLite database file.

SHEPHERD — site overview

general notes

Each structure is one component; larger buildings are the more central ones. Every part of the system communicates the same way: by reading and writing one shared SQLite database file — the tall building in the middle. A command saves its change to the file; the supervisor checks the file a few times a second and acts on what it finds.
